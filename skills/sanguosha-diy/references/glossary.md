# 三国杀术语表

## 技能类型

| 术语 | 定义 |
|------|------|
| 锁定技 | 满足条件时必须发动，不能选择不发动 |
| 限定技 | 每局游戏只能发动一次 |
| 觉醒技 | 满足特定条件后永久改变武将状态（通常扣减体力上限） |
| 转换技 | 两种状态交替切换，每次发动后切换状态 |
| 主公技 | 仅主公身份时可发动 |
| 隐匿技 | 满足条件前不可见，条件满足后解锁 |
| 使命技 | 达成使命后获得增益，失败则失去技能 |

## 阶段术语

| 术语 | 说明 |
|------|------|
| 准备阶段 | 回合开始，判定阶段之前 |
| 判定阶段 | 处理延时类锦囊（乐不思蜀、兵粮寸断、闪电） |
| 摸牌阶段 | 摸两张牌（默认） |
| 出牌阶段 | 使用/打出牌 |
| 弃牌阶段 | 手牌超过上限时弃置 |
| 结束阶段 | 回合结束 |

## 牌类术语

| 术语 | 说明 |
|------|------|
| 基本牌 | 杀、闪、桃、酒 |
| 锦囊牌 | 延时类（乐/兵/闪电）和非延时类（过河拆桥、顺手牵羊等） |
| 装备牌 | 武器、防具、+1/-1 马 |
| 属性杀 | 火杀、雷杀 |
| 无属性杀 | 普通杀 |

## 伤害术语

| 术语 | 说明 |
|------|------|
| 普通伤害 | 无属性 |
| 火焰伤害 | 火杀、火攻等 |
| 雷电伤害 | 雷杀、闪电等 |
| 体力流失 | 不是伤害，不能触发"受到伤害时"类技能 |

## 常用动词（官方标准用词）

- 使用（一张牌）
- 打出（一张牌响应）
- 弃置（从手牌/装备区移除）
- 获得（从某处拿到手牌）
- 摸（从牌堆顶摸牌）
- 展示（翻开让所有人看到）
- 交给（将牌给另一名角色）
- 令（使另一名角色执行某动作）
- 视为（某牌当另一张牌使用）
- 当（同"视为"）
